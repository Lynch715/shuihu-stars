# 水浒群星录 · 立绘生产规范

给 GPT 出图用。核心目标：**100+ 张画风统一，但每个人一眼能认出来不是同一个人**。

---

## 一、防「同脸」的机制

批量出图最常见的失败是所有人一张标准帅脸，只有发型和兵器不同。原因是 prompt 只描述了身份和道具，没描述**脸**。

本规范的做法：

1. **固定块写死** —— 画风、媒介、构图、色调、背景、画幅，每张一字不改。这保证统一。
2. **变量块强制填满 8 个维度** —— 年龄数字 / 肤色 / 脸型 / 眉 / 眼 / 须 / 独有记号 / 体型。缺一个维度，模型就会往默认脸上退。
3. **年龄和肤色是最强杠杆** —— 模型自己几乎不会主动变这两项。水浒里从十八九岁的史进到五十多的老将，从「面黑」的宋江到「浑身雪练也似白肉」的张顺，跨度极大，一定要写进去。
4. **每人一个独有记号** —— 青记、朱砂记、刺青、疤、獠牙、光头戒疤、道髻、头陀箍。这是辨识度的锚点。
5. **负面词里明确禁掉同质化** —— `idealized symmetrical face`、`generic handsome young man`、`same face` 必须在 negative 里。

---

## 二、固定风格块（每张原样粘，不要改）

```
STYLE: Traditional Chinese painting on aged silk, Ming-dynasty woodblock-print
sensibility. Fine iron-wire line drawing for contours and drapery — confident,
unbroken, even-pressure brush strokes. Flat color washes over the linework,
minimal shading, no gradients on skin.

PALETTE: ink black, aged silk beige ground (#e0d5be), muted cinnabar red,
indigo blue, ochre, moss green, bone white. Desaturated and earthy throughout.
No bright or neon colors.

COMPOSITION: single figure, waist-up, three-quarter view, centered, head in the
upper third. Vertical 3:4 canvas.

BACKGROUND: bare silk with only a faint ink-wash haze. No scenery, no objects,
no buildings, no landscape elements.

FINISH: subtle woven silk texture, slight age-toning at the edges.
No text, no seal, no signature, no border, no frame.
```

## 三、固定负面词（每张原样粘）

```
NEGATIVE: idealized symmetrical face, generic handsome young man, same face,
interchangeable features, beauty-filter skin, anime, manga, chibi, modern
haircut, modern clothing, photorealistic, 3D render, CGI, glossy skin, bloom,
lens flare, oversaturated, neon, full body, multiple figures, crowd, background
scenery, buildings, landscape, text, watermark, signature, logo, frame, border
```

## 四、变量块模板

```
SUBJECT: a {年龄} year old {体型} {身份}, {肤色} complexion.
FACE: {脸型}; {眉}; {眼}; {鼻口}; {须}.
MARK: {独有记号}
HEAD: {发型/头饰}
DRESS: {服饰}
WEAPON: {兵器与持法}
BEARING: {气质与动势}
```

八个维度的取值库（填表时从这里取，别自由发挥）：

| 维度 | 取值 |
|---|---|
| 年龄 | 18 / 22 / 25 / 28 / 32 / 35 / 40 / 45 / 50 / 55 |
| 体型 | slight / wiry / lean / sturdy / broad-shouldered / heavyset / massive / short and thick |
| 肤色 | dark brown, weathered / sallow yellow / ruddy jujube-red / pale ivory / sunburnt copper / sallow and sickly / purplish-black / snow-pale |
| 脸型 | round / square-jawed / long and narrow / gaunt / lumpy and irregular / broad and flat / fine-boned |
| 眉 | silkworm-curved / thick as painted lacquer / bristling upward / sparse and thin / eight-character slanted / knitted and heavy |
| 眼 | phoenix eyes (long, upswept) / round glaring eyes / narrow slits / deep-set / apricot-round / cold and bright |
| 须 | clean-shaven / thin moustache over the lip / three-strand long beard to the chest / full jaw beard / bristling tiger whiskers / yellow-red beard / wispy chin hair |
| 记号 | 见每人一条，不可省略 |

## 六、出图参数

| 项 | 值 |
|---|---|
| 画幅 | 3:4 竖构图 |
| 出图尺寸 | 至少 768×1024，越大越好（后期我压） |
| 格式 | PNG 或 JPG 都行，我统一转 WebP |
| 命名 | 用上面每条标题后的英文 id，如 `lin_chong.png` |
| 数量 | 同一个人出 3–4 张挑一张，同脸率会明显下降 |

**出图顺序建议**：先出 06 林冲 / 22 李逵 / 30 张顺 / 31 阮小七 / 09 花荣 这五张。这五个人的年龄、肤色、体型、气质跨度最大——如果这五张放一起明显是五个不同的人，说明 prompt 有效，可以批量往下跑；如果还是一张脸，把 FACE 和 MARK 那两行再加重。

## 七、我这边的后处理

图出好丢给我，我负责：

1. 统一裁切到 3:4，人物居中
2. 色调统一（拉到宣纸底同一套色域，避免 100 张色温飘）
3. 压到 WebP，详情页用 320×440，卡片用 120×160 小图
4. 生成 manifest，按 id 挂进 `portrait` 字段
5. base64 内嵌进单文件

数据里加 `portrait` 字段：有图就显示立绘，没图回落到代码生成的人物牌。所以你出一张我接一张，不用等齐。
